# Context-Identifiability Boundary Audit — 2026-08-23

## Scope

This audit reviews the context-indexed extension of [`../supplementary/selection_equivalence.md`](../supplementary/selection_equivalence.md). It is deliberately outside the locked T1–T5 / E1–E5 core and does not add `T6`, `S2.14`, or `E6`.

The target question is:

> Does observing several policy/intervention-specific first-person laws identify an Everett accessibility mechanism once a behavior-matched classical selection null is admitted?

The audited answer is conditional:

- **no**, if the classical null may retune its selection channel independently by context;
- **potentially**, if both models obey independently motivated cross-context restrictions;
- **not automatically empirically**, because the quantities entering a mathematical restriction must themselves be identifiable on an aligned observable state space.

## H — falsifiable hypotheses

### H1: unrestricted context-specific representability

For each context `c`, let `mu_c` be a probability measure on `(Omega,F)` and let `Q_c << mu_c`. Define

```math
r_c=\frac{dQ_c}{d\mu_c}.
```

Then a classical record process with

```math
N_c\mid(\omega,c)\sim\operatorname{Poisson}(r_c(\omega))
```

has record-size-biased law exactly equal to `Q_c`.

### H2: shared-selection restriction

If one nonnegative measurable selection function `a(omega)` is used in every context,

```math
Q_c(B)
=
\frac{E_{\mu_c}[\mathbf 1_Ba]}{E_{\mu_c}[a]},
```

and all base laws are equivalent to a common reference measure, then

```math
r_c
=
\frac{a}{Z_c},
\qquad
Z_c=E_{\mu_c}[a],
```

so for any pair `c,d`,

```math
\frac{r_c}{r_d}
=
\frac{Z_d}{Z_c}
```

is constant almost everywhere on the common positive-density support.

Conversely, a family with `r_c=a/Z_c` is generated by that shared selection rule because normalization forces `Z_c=E_{mu_c}[a]`.

### H3: operational-testability limitation

A violation of the latent density-ratio condition is not automatically an empirical falsification unless the base and selected laws are identifiable on a common observable state space. Projection can hide latent violations, and context-dependent observation maps can create observed distribution differences even under a shared latent selector.

## T — proof and stress tests

### T1: exact context-specific Poisson representation

Because `Q_c` is a probability measure,

```math
r_c\ge0,
\qquad
E_{\mu_c}[r_c]=1.
```

For the Poisson construction,

```math
E[N_c\mid\omega,c]=r_c(\omega).
```

Hence

```math
E_{\mu_c}[N_c]=1
```

and for every measurable `B`,

```math
E_{\mu_c}[N_c\mathbf 1_B]
=
E_{\mu_c}[r_c\mathbf 1_B]
=
Q_c(B).
```

Therefore

```math
\frac{E_{\mu_c}[N_c\mathbf 1_B]}{E_{\mu_c}[N_c]}
=
Q_c(B).
```

No boundedness or finite second moment is required. Integrability is automatic because `E_{mu_c}[r_c]=1`.

### T2: bounded Bernoulli representation

If `r_c<=M_c<infinity` almost surely, then

```math
P(A_c\mid\omega,c)=\frac{r_c(\omega)}{M_c}
```

is a valid acceptance probability and conditioning on `A_c` reproduces `Q_c`. This is the earlier bounded ascertainment proposition applied context by context.

### T3: shared-selection necessity

Under one shared `a`,

```math
dQ_c
=
\frac{a}{E_{\mu_c}[a]}d\mu_c,
```

so

```math
r_c=\frac{a}{Z_c}.
```

Pairwise ratios are therefore constant on the common support.

### T4: shared-selection converse

Assume

```math
r_c=\frac{a}{Z_c}
```

for a common nonnegative `a` and positive `Z_c`. Since `Q_c` is normalized,

```math
1
=
E_{\mu_c}[r_c]
=
\frac{E_{\mu_c}[a]}{Z_c},
```

thus

```math
Z_c=E_{\mu_c}[a].
```

Substitution recovers the shared-selection law exactly.

### T5: same-base strengthening

If every context has the same base law `mu`, then each `r_c` integrates to one under the same measure. If `r_c/r_d=k` is constant, then

```math
1=E_\mu[r_c]=kE_\mu[r_d]=k,
```

so

```math
r_c=r_d
\qquad \mu\text{-a.s.}
```

for every pair of contexts under the shared latent selection null.

This concerns the selected law on the common latent/base state. Policy-dependent maps from that state to outcomes can still produce different observed outcome distributions.

## Numerical property tests

A private audit script generated 20,000 random finite-state pairs with 2–11 states.

For arbitrary positive `mu_c` and `Q_c`, it checked the exact record-size identity numerically by reconstructing

```math
\widetilde Q_c(i)
\propto
\mu_c(i)r_c(i).
```

Result:

```text
maximum absolute representation error = 3.3306690738754696e-16
```

For random shared selectors `a`, it checked constancy of

```math
r_0(i)/r_1(i).
```

Result:

```text
maximum numerical deviation from constancy = 7.105427357601002e-15
```

For arbitrary nonproportional density-ratio pairs it reconstructed the second context from `a=r_0` and checked for accidental shared-null fits.

Result:

```text
false shared-null fits among tested nonconstant ratios = 0
```

These tests are implementation/sanity checks only; the exact claims are established by the proofs above.

## Projection stress tests

### P1: shared latent selection can still yield different observed distributions

Let

```math
\Omega=\{0,1\},
\qquad
\mu=(1/2,1/2),
\qquad
a=(1,3).
```

The shared selected latent law is

```math
Q^\star=(1/4,3/4).
```

If context 0 observes `X_0=omega` while context 1 observes `X_1=1-omega`, then the observed laws are

```math
P(X_0=\cdot)=(1/4,3/4),
```

and

```math
P(X_1=\cdot)=(3/4,1/4).
```

Thus differing observed outcome distributions do not by themselves falsify a shared latent selector when the observation/trajectory map changes with context.

### P2: a latent shared-null violation can disappear after projection

Let four latent states have uniform base law and define normalized selected laws proportional to

```math
(4,2,1,1)
```

and

```math
(2,4,1,1).
```

The latent cross-context density-ratio ratios are

```math
(2,1/2,1,1),
```

so no single shared selector generates both latent laws.

Now project states 1–2 to observable `A` and states 3–4 to observable `B`. Both selected laws project to

```math
(3/4,1/4).
```

The latent violation is therefore completely invisible in the projected observable distribution.

### Audit consequence

A cross-context density-ratio theorem is a structural identification result, not an automatic experimental protocol. Any empirical use must establish that the quantities entering the restriction are recoverable after the relevant observation/trajectory map.

## C — competing explanations and failure modes

1. **Context-specific classical selection:** unrestricted `a_c` or record multiplicity reproduces each `Q_c` exactly.
2. **Changing outcome map:** observed distributions can differ because `X_c=T_c(omega)` changes while latent selection is fixed.
3. **Changing base law:** `mu_c` differences can create observed changes independent of selection changes.
4. **Projection loss:** latent density-ratio violations can disappear under coarse observation.
5. **Post hoc restriction:** choosing a shared-null restriction only after seeing the data invalidates its evidential role.
6. **Asymmetric model comparison:** allowing arbitrary policy dependence for QBS while forbidding it for the classical null creates a straw null.
7. **Estimation error:** even when `r_c` is identifiable in principle, finite-sample density-ratio estimation requires a separate statistical validity analysis.
8. **Support mismatch:** pairwise density-ratio comparisons require common support or an explicitly handled partial-overlap formulation.

## Prior-art cross-check

The context-indexed boundary is consistent with established selection-model identification problems.

- James J. Heckman, "Sample Selection Bias as a Specification Error," *Econometrica* 47(1), 153–161 (1979), DOI `10.2307/1912352`, is a canonical sample-selection analysis.
- Wang Miao, Peng Ding, and Zhi Geng, "Identifiability of Normal and Normal Mixture Models with Nonignorable Missing Data," *JASA* 111(516), 1673–1683 (2016), DOI `10.1080/01621459.2015.1105808`, explicitly shows that nonignorable missingness models can remain unidentified without additional assumptions.
- Wang Miao and Eric Tchetgen Tchetgen, "Identification and inference with nonignorable missing covariate data," *Statistica Sinica* 28(4), 2049–2067 (2018), DOI `10.5705/ss.202016.0322`, shows how additional auxiliary/shadow-variable structure can restore identification under stated conditions.

These works do not prove the QBS-specific propositions; the propositions above are elementary measure-theoretic consequences. Their relevance is methodological: selected data do not identify an unrestricted selection mechanism without additional structure.

## D — audit decision

**PASS — exact mathematical boundary, with an important operational qualification.**

The following survived proof review and finite-state stress testing:

- arbitrary context-specific absolutely continuous observer laws have exact classical record-size-biased representations;
- a shared context-invariant selection function implies proportional cross-context Radon--Nikodym densities;
- the converse holds under the stated common-function representation;
- with a common base law, proportionality strengthens to equality of normalized density ratios;
- multiple contexts alone do not identify the mechanism when context-specific selection is unrestricted.

The phrase **testable restricted null** is acceptable only when accompanied by the operational requirements above. Without identified base/selected laws on a common observable state space, the density-ratio condition is not yet an empirical test.

## U — remaining uncertainty

The audit does **not** establish that a physically motivated Everett accessibility law supplies a useful shared cross-context restriction. That remains open.

The next high-value target is to specify a candidate physical bridge with:

1. a low-dimensional/predeclared cross-policy accessibility law;
2. independently measured physical inputs;
3. a common observable state or justified measurement map;
4. held-out contexts in which the law predicts `Q_c` without retuning;
5. classical structural nulls given comparable degrees of freedom;
6. a statistical test with uncertainty and model-selection control.

Until such a model exists, the context-indexed result should be treated primarily as a **no-go / identification-burden theorem**, not as positive evidence for QBS physics.

## ERROR CHECK

1. The Poisson construction uses the Radon--Nikodym density itself as a dimensionless conditional mean; it is finite almost surely because it is integrable with mean one.
2. The Bernoulli construction additionally requires essential boundedness.
3. The shared-selector necessity and converse concern laws on the same aligned measurable state space.
4. The same-base strengthening concerns latent/base-state density ratios, not necessarily observed outcome distributions after policy-dependent maps.
5. Projection can both hide latent violations and create observed differences unrelated to selection changes.
6. Failure of one restricted classical null does not identify Everett; more flexible classical selection models may remain observationally equivalent.
7. The prior-art comparison is methodological, not a novelty claim for generic selection-model identifiability.
8. T1–T5, E1–E5, and the numbered S2 family are untouched by this audit.

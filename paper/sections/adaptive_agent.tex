\section{Adaptive-Agent Mechanism}

A central modeling question is whether positive outcome--accessibility alignment must be inserted exogenously. We instead consider an adapted agent with environment state $X_t$, internal belief state $B_t$, evaluation signal $Y_t$, and later outcome $U_T$.

Adaptation can create predictive information,
\[
I(B_t;X_t)>0,
\]
and temporal environment structure can make current state informative about later outcomes,
\[
I(X_t;U_T)>0.
\]
These information relations alone do not guarantee positive Pearson correlation. The useful additional condition is directional calibration: $\mathbb E[U_T\mid Y_t=y]$ should be nondecreasing in $y$. If accessibility is also nondecreasing in the evaluation signal, the model naturally produces positive outcome--accessibility covariance under corresponding regularity assumptions.

The intended causal chain is
\[
\text{adaptation}
\rightarrow
\text{predictive internal model}
\rightarrow
\text{ordered evaluation signal}
\rightarrow
\text{outcome-aligned accessibility}.
\]

Experiment E2 tests the minimal version of this mechanism in a nonlinear environment. A misspecified model that cannot represent the relevant interaction fails to produce predictive alignment, while a small interaction-capable model succeeds. This provides a classical mechanism for endogenous correlation but does not establish a physical Everettian accessibility map.

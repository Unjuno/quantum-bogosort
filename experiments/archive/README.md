# Exploratory Experiment Archive

The five experiments E1–E5 are the locked core. Earlier or secondary studies should be documented here rather than silently discarded.

## Archive categories

- recognition-time / recursive experiments;
- accessible-measure decay and generating-function checks;
- multi-observer normalization and zero-sum conditioning;
- selectivity-frontier and measure-constrained optimization;
- evidence-activation sample-size studies;
- adaptation monotonicity and alignment-threshold sweeps;
- adaptation accuracy / total-effect sweeps;
- earlier branch-recognition and probabilistic-execution variants.

## Archiving rule

An archived experiment should record:

- research question;
- exact parameterization;
- code or notebook source if available;
- output file names;
- whether the result was retained, superseded, or rejected;
- the reason for supersession when applicable.

The archive is intended to make the path to the final model auditable. Superseded experiments must not be cited as current evidence without clearly stating their status.

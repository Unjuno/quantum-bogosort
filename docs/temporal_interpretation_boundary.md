# Temporal interpretation boundary

This document separates two mathematically compatible but conceptually different uses of time in QBS-style observer models.

## 1. Retrospective weighted description

The normalized weighted measure can be restricted to a present-state variable `Z_t` even when the accessibility weight `S_T` is defined on a later continuation:

```math
P_{FP}(Z_t\in A)
=
\frac{E[\mathbf 1_{\{Z_t\in A\}}S_T]}{E[S_T]}.
```

This is an exact change-of-measure identity once the weighted measure is adopted. It can be used retrospectively to describe how present states are represented inside a future-weighted ensemble.

It does **not** by itself imply that a future outcome causally determines, changes, or reveals a unique ontological observer identity at the earlier time.

## 2. Past-adapted prospective model state

For prospective prediction, any state used at time `t` to determine policy, recognition, self-location, or the next predictive law should depend only on the information available by `t`.

If `H_t` is the declared information history, the prospective model state must be `H_t`-measurable. Future observations may later score the prediction, but they are not permitted to redefine the earlier state after the fact.

Thus:

```math
\text{future observation}
\longrightarrow
\text{score of an earlier prediction}
```

is allowed, while

```math
\text{future favorable outcome}
\longrightarrow
\text{retroactive relabeling of earlier self-location}
```

is not part of the prospective protocol.

## 3. Consciousness gaps and observational equivalence

During an interval with no reportable conscious observation, such as ordinary sleep, more than one latent continuity description may be compatible with the same available record before and after the interval.

If two latent descriptions induce the same observable history up to time `t`, the history alone does not identify which latent ontology is correct. This underdetermination is symmetric:

- it does not prove a branch switch, observer reassignment, or alternative continuity rule;
- it also does not make one latent continuity ontology empirically unique merely by assertion.

The correct conclusion at the observational level is non-identification unless an additional model supplies prospectively different consequences.

## 4. Underdetermination is not unconstrained freedom

Observational equivalence does not permit arbitrary post hoc stories. A candidate observer model must still specify, before the outcomes used for evaluation:

- its state space and transition/accessibility rule;
- normalization and support conditions;
- temporal adaptation to the declared history;
- sequential coherence;
- cross-context restrictions where claimed;
- observable consequences or explicit acknowledgement that the ontology remains empirically underdetermined.

Therefore:

```math
\text{underdetermined}
\neq
\text{unconstrained}.
```

## 5. Empirical consequence

The latent continuity ontology itself need not be directly observable for a concrete model to be empirically testable. What can be tested is a **prospective prediction** generated from that ontology plus its transition/accessibility law.

The companion protocol [`../supplementary/prospective_recognition_protocol.md`](../supplementary/prospective_recognition_protocol.md) therefore evaluates recognition-dependent models by predeclared longitudinal predictions, external exposure assignment where feasible, behavior/expectancy controls, attrition/selection controls, and held-out sequential scoring.

A later favorable history is evidence only to the extent that it was predicted in advance relative to specified alternatives. It is not retrospective proof that an unobserved transition occurred earlier.

## Non-claims

This boundary does not claim that observer switching occurs during sleep, that consciousness controls quantum branching, that future outcomes causally alter the past, or that ordinary identity continuity is false. It states only the distinction between retrospective change-of-measure descriptions, past-adapted prospective model states, and observational non-identification of latent continuity when the available records do not distinguish the alternatives.

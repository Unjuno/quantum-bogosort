# Randomized-Context Shared-Selection Diagnostic

This note gives an **unnumbered exact diagnostic** that turns part of the context-identifiability boundary into a finite-sample experiment under additional randomized-design assumptions. It does not add `T6`, `S2.14`, or `E6`, and it is not evidence for an Everett bridge by itself.

The key idea is to randomize context independently of the pre-treatment state and ask whether a context-invariant selection mechanism preserves that randomization after conditioning on being observed.

## Setup

Consider independent experimental units with:

```math
C\sim\mathrm{Bernoulli}(p),
\qquad
0<p<1,
```

where `C` is a randomized policy/intervention context. Let the pre-treatment latent state satisfy

```math
\Omega\sim\mu,
\qquad
C\perp\!\!\!\perp\Omega.
```

A binary inclusion/record indicator is generated by

```math
A\mid(C=c,\Omega=\omega)
\sim
\mathrm{Bernoulli}(s_c(\omega)),
```

with

```math
0\le s_c(\omega)\le1.
```

Let

```math
W=T(\Omega)
```

be a pre-treatment observable or stratum label recorded for selected units.

| Symbol | Meaning | Units | Domain / assumption | Type |
|---|---|---|---|---|
| `C` | randomized context | none | Bernoulli with known probability `p` | random variable |
| `p` | context-1 assignment probability | none | `0<p<1` | scalar |
| `Omega` | pre-treatment latent state | none | independent of `C` before selection | random element |
| `A` | inclusion / observed-record indicator | none | binary | random variable |
| `s_c` | context-specific inclusion selector | probability | measurable, values in `[0,1]` | function |
| `W` | pre-treatment observable stratum | none | measurable function of `Omega` | random variable |
| `n_w` | selected sample size in stratum `w` | count | nonnegative integer | statistic |
| `K_w` | number of selected context-1 units in stratum `w` | count | `0<=K_w<=n_w` | statistic |

The **shared-selection null** is

```math
H_0:
\qquad
s_0(\omega)=s_1(\omega)=s(\omega)
```

for `mu`-almost every state relevant to selection.

## Exact randomized-context preservation theorem

Under `H_0`, for every latent state with positive selected probability,

```math
P(C=1\mid A=1,\Omega=\omega)=p.
```

Hence

```math
C\perp\!\!\!\perp\Omega\mid A=1,
```

and therefore for every measurable pre-treatment observable `W=T(Omega)`,

```math
P(C=1\mid A=1,W)=p
```

almost surely on selected strata with positive probability.

### Proof

Under randomization and the shared selector,

```math
P(C=1,A=1\mid\Omega=\omega)
=
p\,s(\omega),
```

while

```math
P(A=1\mid\Omega=\omega)
=
(1-p)s(\omega)+ps(\omega)
=
s(\omega).
```

Whenever `s(omega)>0`, division gives

```math
P(C=1\mid A=1,\Omega=\omega)
=
p.
```

Thus the selected conditional law factorizes into the original randomized context law and a reweighted state law. Applying any measurable map `W=T(Omega)` preserves the independence claim. `QED`

## Full-state converse

The preservation law is also sufficient for a shared selector when the full latent state is observed.

Assume randomization as above and suppose, wherever the denominator is positive,

```math
P(C=1\mid A=1,\Omega=\omega)=p.
```

For arbitrary context-specific selectors,

```math
P(C=1\mid A=1,\Omega=\omega)
=
\frac{p\,s_1(\omega)}{(1-p)s_0(\omega)+ps_1(\omega)}.
```

Equating this with `p` and using `0<p<1` gives

```math
s_1(\omega)=s_0(\omega)
```

on every state with positive selected probability. Thus full-state randomization preservation is equivalent to context-invariant binary selection under the stated design.

This converse does **not** survive arbitrary projection. Equality after observing only `W=T(Omega)` is necessary but generally not sufficient for latent selector equality.

## Finite-sample exact test on observable strata

Suppose `W` takes values in a finite set of **predeclared** strata. Under the shared-selection null, selected context labels remain Bernoulli with the original randomization probability inside every stratum:

```math
K_w\mid n_w
\sim
\mathrm{Binomial}(n_w,p).
```

Therefore each stratum admits an exact finite-sample binomial test. If there are `m` predeclared strata and each test is run at level

```math
\frac{\alpha}{m},
```

then Bonferroni gives conditional family-wise error control

```math
P(\text{at least one false rejection}\mid\{n_w\})
\le
\alpha.
```

No density-ratio estimation and no separate estimate of the latent base law are required for this test. The known randomized assignment probability supplies the reference distribution.

The repository implementation uses `p=1/2`, two predeclared binary `W` strata, conservative equal-tail exact binomial p-values, and Bonferroni level `alpha/2` per stratum.

## Why pre-treatment observables matter

The diagnostic should be applied to variables fixed before the randomized context can causally change the trajectory. If a post-treatment outcome is used instead, context-dependent policy effects can alter its distribution even when the selector is shared, reproducing the earlier projection/outcome-map ambiguity.

Thus the experiment separates:

```math
\text{randomized context}
\longrightarrow
\text{policy / trajectory effects}
```

from the specific null restriction

```math
\text{selection does not depend on randomized context given the pre-treatment state}.
```

## Simulation design

The deterministic script [`randomized_context_diagnostic.py`](randomized_context_diagnostic.py) uses four latent states

```math
\omega=(W,L),
\qquad
W,L\in\{0,1\},
```

with uniform base probability and equal context randomization.

It compares four mechanisms.

1. **Shared null.** A nontrivial selector depends on both `W` and latent `L` but is identical across contexts.
2. **Rate shift.** The selector is multiplied upward in one context and downward in the other. This changes context prevalence in every observed `W` stratum.
3. **Observed composition shift.** Context-specific selection moves mass in opposite directions across `W` while preserving the overall context marginal by symmetry.
4. **Latent projection-blind shift.** Context-specific selection acts only through unobserved `L`; after marginalizing `L`, both observed `W` strata retain exactly the randomized context distribution.

The last mechanism is a deliberate counterexample: it violates shared latent selection while remaining invisible to the proposed observable test.

## Deterministic Monte Carlo results

The script uses NumPy seed `20260823`, `10,000` replications per cell, selected sample sizes `200`, `500`, and `1000`, and nominal family-wise level `0.05`.

### Shared-null calibration

| selected `n` | rejection rate |
|---:|---:|
| 200 | 0.0351 |
| 500 | 0.0420 |
| 1000 | 0.0413 |

The empirical rate stays below the nominal `0.05`, consistent with the exact conservative Bonferroni construction.

### Power against observable violations

| `gamma` | rate shift, `n=200` | `n=500` | `n=1000` | composition shift, `n=200` | `n=500` | `n=1000` |
|---:|---:|---:|---:|---:|---:|---:|
| 0.1 | 0.1690 | 0.4266 | 0.7439 | 0.1734 | 0.4184 | 0.7272 |
| 0.2 | 0.6066 | 0.9646 | 1.0000 | 0.5844 | 0.9606 | 0.9999 |
| 0.4 | 0.9971 | 1.0000 | 1.0000 | 0.9957 | 1.0000 | 1.0000 |

The two alternatives are detected for different reasons: rate shift changes the randomized context fraction within both strata in the same direction, while composition shift changes the two strata in opposite directions even though the overall selected context fraction remains exactly `1/2`.

### Projection-blind counterexample

For the latent-only alternative, the observed quantities satisfy exactly

```math
P(C=1\mid A=1,W=0)
=
P(C=1\mid A=1,W=1)
=
\frac12,
```

for every tested effect size. Yet at `gamma=0.4`, the latent selected probabilities differ strongly:

```math
P(L=1\mid C=0,A=1)
\approx
0.310026,
```

and

```math
P(L=1\mid C=1,A=1)
\approx
0.689974.
```

The resulting rejection rates remain near the null level:

| `gamma` | `n=200` | `n=500` | `n=1000` |
|---:|---:|---:|---:|
| 0.1 | 0.0388 | 0.0382 | 0.0424 |
| 0.2 | 0.0406 | 0.0445 | 0.0426 |
| 0.4 | 0.0370 | 0.0437 | 0.0434 |

This is not a failure of the theorem. It demonstrates its exact operational scope: randomized-context balance can falsify selector dependence that reaches the observed pre-treatment strata, but it cannot reveal context dependence that is fully hidden by projection.

## H / T / D / C / U

### H — falsifiable hypothesis

Under randomized context assignment independent of the pre-treatment state, a context-invariant binary selector preserves the randomized context probability within every selected pre-treatment observable stratum.

### T — minimal validation

1. Prove exact preservation and the full-state converse.
2. Use an exact finite-sample stratum test with family-wise error control.
3. Simulate a nontrivial shared null.
4. Simulate a pure rate-shift violation.
5. Simulate an equal-marginal observed-composition violation.
6. Simulate a latent projection-blind violation.

### D — decision

**PASS for the stated randomized-design diagnostic.**

The preservation theorem is exact, the finite-sample test has conditional Bonferroni error control, and deterministic simulations show calibration under the shared null plus increasing power against observable selector violations.

**FAIL as a universal bridge-identification procedure.**

The latent projection-blind alternative survives the observable test by construction.

### C — competing explanations / failure modes

- broken or undocumented randomization;
- context assignment correlated with the pre-treatment state;
- differential missingness before the modeled selector;
- post-treatment `W` mistakenly treated as pre-treatment;
- context-dependent measurement of `W`;
- multiple data-dependent strata without multiplicity correction;
- dependent/clustered experimental units invalidating the iid binomial model;
- latent context dependence that integrates out inside every observed stratum;
- rejection of the shared-selector null caused by an ordinary classical context-dependent selection mechanism rather than Everettian physics.

### U — remaining uncertainty

The result supplies an **operational falsification test for one restricted shared-selection null**. It does not establish that Everett predicts the alternative, and it does not identify the physical cause of a rejection.

A stronger future design would need independently motivated physical variables that make the relevant selector state sufficiently observable to reduce the projection-blind equivalence class.

## QBS implication

This experiment improves the earlier bridge gate in one specific way. A randomized policy/context variable can serve as an instrument-like design variable because its base distribution is externally fixed. Under a context-invariant accessibility/selection law, selection cannot manufacture an association between that randomized variable and pre-treatment state.

Therefore a concrete QBS/Everett model that predicts context-dependent accessibility can be compared against a shared classical selector without estimating the full latent base law, provided the model states in advance which pre-treatment observables should carry the dependence.

But a rejection means only:

> the randomized-context shared-selector null is false on the observed state description.

It does **not** mean:

> Everettian observer selection has been identified.

## ERROR CHECK

1. **Randomization is essential.** If `C` and `Omega` are associated before selection, selected context imbalance is not diagnostic of context-dependent selection.
2. **Binary inclusion model.** The exact finite-sample theorem is stated for independent Bernoulli inclusion across experimental units. Record-multiplicity models require a separate dependence/sampling treatment before reusing the binomial test.
3. **Known assignment probability.** The test uses the externally specified randomization probability `p`; estimating it from the selected sample would erase the principal reference restriction.
4. **Pre-treatment restriction.** `W` must not be causally changed by context assignment.
5. **Multiplicity.** Strata must be fixed before inspecting selected outcomes, or the testing procedure must correct for adaptive selection.
6. **Projection.** Observable balance is necessary but not sufficient for latent shared selection.
7. **Full-state converse.** The converse holds only where selected probability is positive and under `0<p<1`.
8. **Mechanism interpretation.** Rejecting this classical null does not identify Everett; it only rules out that restricted selection structure.
9. **Simulation role.** Monte Carlo results are stress tests, not the proof of finite-sample validity.
10. **Core identity.** T1–T5, E1–E5, and numbered S2 results are unaffected.

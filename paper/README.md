# Manuscript Scaffold

This directory contains the evolving manuscript source. It is intentionally incomplete during the public-review phase.

## Planned structure

1. Abstract
2. Introduction
3. Formal Model
4. Main Theorems
5. Adaptive-Agent Mechanism
6. Experiments
7. Everett Interpretation
8. Limitations and Falsifiability
9. Discussion
10. Appendix
11. References

## Writing rule

Every substantive statement should be identifiable as one of:

- theorem / proposition,
- simulation result,
- model assumption,
- Everett bridge assumption,
- interpretation,
- open problem.

The manuscript must not state a simulation-supported classical mechanism as an Everettian physical result.

## Current status

The core theorem set and five experiment families are stable enough to scaffold the manuscript. Related work, publication figures, and the physical Everett bridge remain incomplete.
